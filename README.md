# qa-factory

The QA part of an AI software factory, built as working code that runs on one machine, on
Temporal. AI writes the tests; deterministic tools check that they are not misleading; a person
approves a readable version; approved tests join the regression suite.

Start with `docs/status.md`. The rules are in `CLAUDE.md`, the requirements in `docs/brief.md`.

`just setup` once after cloning, then `just check`.
